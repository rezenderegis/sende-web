Mandar uma mensagem de recompra 30 dias depois de toda venda parece simples, mas ignora que cada cliente consome o produto num ritmo diferente. Quem compra ração para um pet grande recompra mais rápido que quem compra para um filhote. Usar um prazo fixo para todo mundo é a razão pela qual boa parte dessas campanhas parece spam.

O ajuste certo é calcular o intervalo médio de recompra por cliente, com base no histórico de pedidos dele, e disparar a mensagem um pouco antes desse ciclo terminar, não depois. Se o cliente já ficou sem o produto quando a mensagem chega, ela parece atrasada em vez de útil.

<Callout type="tip" title="Use o histórico, não a média geral">
Clientes diferentes têm ciclos diferentes. Se sua base tem produtos com consumo muito variado, agrupe por categoria de produto antes de definir o intervalo — uma média única geral vai errar para os dois extremos.
</Callout>

Outro ponto que faz diferença é o tom da mensagem: em vez de "compre de novo", funciona melhor perguntar se o cliente já está acabando o produto e oferecer para já deixar o próximo pedido pronto. Isso transforma uma cobrança disfarçada de venda em um serviço que o cliente agradece.
