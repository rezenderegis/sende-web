Tag e campo personalizado parecem a mesma coisa à primeira vista — os dois guardam informação sobre o contato. Mas usados do jeito errado, viram uma bagunça de categorias que ninguém mais entende seis meses depois.

## Quando usar tag

Tags são boas pra **estado temporário ou classificação rápida**: "aguardando pagamento", "cliente VIP", "não responder mais". Servem pra filtrar e disparar automação — e podem ser removidas quando a situação muda.

## Quando usar campo personalizado

Campos são melhores pra **dado estruturado e permanente**: data de nascimento, plano contratado, cidade. Isso é informação que você quer consultar e usar em mensagem personalizada (`{{nome}}`, `{{plano}}`), não só filtrar.

<Callout type="info" title="Na prática">
Se a informação muda com frequência e serve pra agrupar contatos, é tag. Se é um dado fixo do cliente que você quer usar dentro de uma mensagem, é campo.
</Callout>

Misturar os dois sem critério é o motivo mais comum de uma base de contatos virar impossível de navegar depois de um tempo.
