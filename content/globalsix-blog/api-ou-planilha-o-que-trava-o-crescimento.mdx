Exportar um relatório de um sistema, abrir no Excel, ajustar algumas colunas e importar em outro sistema é, por muito tempo, uma solução razoável. Funciona, não custa nada além do tempo de quem faz, e resolve o problema do dia. O risco é achar que isso vai continuar funcionando conforme a empresa cresce.

O método da planilha tem um limite silencioso: ele depende de alguém lembrar de fazer, fazer certo, e fazer a tempo. Com baixo volume, os erros são raros e fáceis de corrigir na mão. Com volume maior, a mesma tarefa que levava dez minutos passa a levar uma hora, e o espaço para erro cresce na mesma proporção.

<Callout type="tip" title="O sinal de que é hora de mudar">
Se a planilha de integração entre sistemas já tem mais de uma aba, mais de uma pessoa editando, ou já causou um erro que chegou até o cliente, é sinal de que uma integração via API provavelmente custa menos do que continuar do jeito atual.
</Callout>

A diferença entre os dois métodos não é só velocidade. É confiabilidade: uma API bem configurada faz a mesma coisa, da mesma forma, toda vez — sem depender de quem está de folga, sem esquecer uma linha e sem errar uma fórmula. Trocar a planilha pela integração automática costuma ser uma das mudanças mais baratas com retorno mais rápido que uma empresa em crescimento pode fazer.
