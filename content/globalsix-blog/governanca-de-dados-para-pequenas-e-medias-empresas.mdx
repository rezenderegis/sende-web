Governança de dados parece um tema de empresa grande, com cargo dedicado e comitê formal. Mas a parte que mais afeta o dia a dia de uma empresa pequena ou média é bem mais simples: saber onde cada informação importante mora, quem pode mudar ela e o que é considerado a versão correta.

O problema mais comum nessas empresas não é falta de dado, é excesso de versões do mesmo dado. Cliente cadastrado em três planilhas diferentes, com telefone atualizado em uma e não nas outras, é o tipo de bagunça que nenhum sistema resolve por conta própria — resolve só se a empresa decidir qual fonte é a verdadeira.

<Callout type="info" title="Comece definindo as fontes únicas">
Escolha, pra cada tipo de informação importante — cliente, produto, pedido — qual sistema ou planilha é a fonte oficial. Qualquer outro lugar que guarde essa informação deveria puxar dali, nunca manter uma cópia independente.
</Callout>

Outro hábito simples e de alto impacto é definir quem tem permissão pra editar cada tipo de dado, mesmo que de forma informal no começo. Isso evita que um erro de digitação de uma pessoa vire verdade pra empresa inteira, porque ninguém mais vai verificar.

Governança de dados boa não exige ferramenta cara — exige decisão clara sobre o que é verdade e disciplina pra manter isso.
